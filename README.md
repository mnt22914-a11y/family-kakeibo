# 家族の家計簿

家族みんなで使える、スマホ対応の家計管理Webアプリです。

- 収支の入力、カテゴリ別・月別の集計
- カテゴリごとの月予算と残り表示
- 「誰が払ったか」の記録と、立て替えの精算計算
- 家賃・サブスクなどの固定費を毎月自動で記録
- クラウド同期(Supabase)で、家族の入力がすぐ全員に反映
- 個人間の貸し借りの記録(家族どうし・家族以外)
- みんなで一緒の貯金目標(水がたまるタンクで進み具合を表示)
- CSV書き出し(Excelで開けます)

## かんたん入力(開いてすぐの画面)

1. テンキーで金額を打つ
2. 金額カードを **左へスワイプ=支出**、**右へスワイプ=収入**(下の「‹ 支出」「収入 ›」ボタンでも同じ)
3. 出てきたカテゴリのタイルをタップ → その瞬間に保存(日付は今日、支払った人は自分)

- カードは指に合わせて傾き、離すと画面の外へ飛んでいく(軽くはじくだけでも決定)。足りなければバネで戻る。引いた方向に応じてカードが色づき、「← 支出」「収入 →」のラベルが出る
- 選んだカテゴリの絵文字が「今日」の合計へ吸い込まれ、数字が増える。端末の「視差効果を減らす」設定がオンのときは、動きを控えめにする
- カテゴリは **よく使う順** に並ぶ。上の「スーパー」などのボタンは、メモ付きで2回以上入力した内容が自動で並んだもの
- 間違えたら、画面上の通知の **取り消す**。メモや日付、支払った人を直したいときは **詳細**
- 過去の日付やメモ付きで入れたいときは「詳しく入力」。こちらは「続けて入力」でレシートのまとめ入力ができる
- **🧮 電卓**: テンキーの上の「電卓」を押すと + − × ÷ が使えるキーになる。「1200+350×2」のように打つと結果が表示され、そのままスワイプすれば計算結果が金額になる。詳しく入力などの金額欄でも、右端の 🧮 で同じ電卓が出る(式のまま保存しても結果が使われる)
- パソコンでは数字キー・+ − * /・Enter(=)・Backspace・←(支出)・→(収入)でも操作できる
- 家賃やサブスクは「支払い予定」に登録すれば自動で記録される
- 「まとめ」画面に今日の入力状況を表示(使わなかった日や、数日空いた場合も責めない表示)

## まとめ画面

- いちばん上は **今月あと使えるお金**(予算の残り)と、1日あたりの目安
- **動く泡**: カテゴリが絵文字入りの泡になり、下から浮かんできて集まったあとも、ずっとふわふわ漂い続ける。多く使ったものほど大きく濃い。指でなぞると泡が指をよけてかき分けられ、触った場所には波紋が広がる。泡をつかんで放り投げることもできる(パソコンではマウスを上で動かすだけで泡がよける)
  - 泡のまわりの輪は予算の進み具合。8割を超えると黄色、オーバーすると赤の輪と「!」
  - 「カテゴリ / 家族」で切り替えると、誰がいくら払ったかの泡になる
  - 泡をタップすると、その中身の明細が開く
- **収入と支出のバランス**: 収入を100%として「使った / これから払う予定 / 残る見込み」を1本の帯で表示(例: 収入の 37% を使いました)
- 「気をつけたい」には予算の8割を超えたカテゴリだけが出る
- 数字で確かめたいときは「一覧で見る」「6か月の推移を見る」を開く

## 支払い予定(固定費)

「まとめ」→「今月の支払い予定」→「すべて見る」で開きます。

- いちばん上に「この月、これから払うお金」と、合計のうちいくら済んだかの帯
- **次の支払い** を大きく1枚で表示(「あと2日」が大きな数字で出る。3日以内はオレンジで強調)
- その下に「そのあと」「済んだもの」の順で並ぶ。各行の丸がスタンプになっていて、済むと「済」のハンコが押される
- 給料日など **入ってくる予定** は別の枠に分けて表示
- 予定は **毎月 / 毎年(自動車税・年会費など)/ 1回だけ** から選べる。給料日など収入の予定も登録できる
- 日付は登録シートの **カレンダーをタップして選ぶ**。毎月ならその日が毎月、毎年ならその月日、1回だけならその日だけに印が付き、下に「毎月 27日 に記録します」と表示される。「月末」にするチェックもある
- その日になると自動で記録される。金額が違った月は、記録されたあと履歴から直せばよい
- ‹ › で来月以降の予定も確認できる

## 貯金目標(みんなで一緒に)

「まとめ」→「みんなの貯金目標」→「すべて見る」で開きます。

- 目標ごとに、波打ちながら水がたまっていく丸いタンクと、大きな「%」で進み具合を表示
- 期限を入れると「あといくら、毎月いくらで間に合うか」が出る
- だれがいくら入れたかを、メンバー色の帯で表示
- 「貯金する」で入金するとコインが降ってきて、達成した瞬間は紙吹雪
- 貯金は家計の支出・収入には含めない(使ったお金ではないため)

## 個人間の貸し借り

「精算」タブの右上で「立て替え / 貸し借り」を切り替えます。

- 「貸した / 借りた」「家族のだれが」「相手(家族、または家族以外の人の名前)」「金額」を記録
- 同じ相手との貸し借りは差し引きして「たろう → パパ あと ¥5,000」のように表示
- 「返済を記録」で、全額でも一部でも返済を記録できる。返し終わったものは「済」のハンコ付きで折りたたまれる
- **家族どうし(精算に含めるメンバーどうし)の貸し借りは、「立て替え」の精算に自動で入る**。渡す金額はそちらでまとめて計算され、「渡したら記録」で解消する。家族以外との貸し借りや、精算に含めない人(子どもなど)との分は「返済を記録」で個別に管理する
- 貸し借りは家計の支出・収入には含めない

## 2つのモード

| モード | 条件 | データの保存先 |
|---|---|---|
| お試しモード | `js/config.js` が空のまま | その端末のブラウザ内だけ |
| クラウドモード | `js/config.js` に Supabase の値を設定 | Supabase(家族で共有) |

お試しモードで入力したデータは、クラウドモードに切り替えたあと、同じ端末の「設定 → お試しデータの引き継ぎ」から家計に取り込めます(データは端末ごとに保存されているので、入力した端末で取り込みます)。

## パソコンで試す

ターミナルでこのフォルダに移動して、次を実行します。

```sh
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開きます。サンプルデータ入りで見たい場合は <http://localhost:8000/tests/seed.html> を開いてください(お試しデータは上書きされます)。

## クラウド同期の設定(Supabase・無料)

1. <https://supabase.com> でアカウントを作り、「New project」でプロジェクトを作成する
   - Region は `Northeast Asia (Tokyo)` がおすすめ
   - Database Password は控えておく(このアプリでは使いません)
2. 左メニューの **SQL Editor** を開き、`supabase/schema.sql` の中身を全部貼り付けて **Run** を押す
   - 「Success. No rows returned」と出れば成功
3. 左メニューの **Authentication → Sign In / Providers** を開き、ページいちばん上の **User Signups** の枠にある **Confirm email** をオフにして **Save changes** を押す
   - オンのままだと、登録時に確認メールのリンクを開く手間が増えます(家族だけで使うならオフで十分です)
   - **Email** の行の中にある **Enable Email provider** はオンのままにする(オフにすると登録できなくなります)
4. **Project Settings** で次の2つをコピーする
   - **Data API** の Project URL(`https://xxxx.supabase.co`)
   - **API Keys** の Publishable key(`sb_publishable_...`)。Legacy API Keys タブの anon public キーでも可
5. `js/config.js` に貼り付ける

```js
window.KAKEIBO_CONFIG = {
  SUPABASE_URL: 'https://xxxx.supabase.co',
  SUPABASE_ANON_KEY: 'eyJ...',
};
```

> anon キーはもともと公開される前提の鍵です。データは「同じ家計のメンバーしか読み書きできない」ルール(`schema.sql` の RLS)で守られています。
> **service_role キー(secret キー)は絶対に貼らないでください。**

無料プランのプロジェクトは、1週間まったくアクセスがないと一時停止されます。その場合は Supabase の画面から「Restore」で復帰できます。

## 家族での使い方

1. 最初の1人が「新規登録」→「新しく家計を作る」
2. 「設定」に表示される **招待コード** を家族に伝える
3. 家族は同じURLを開いて「新規登録」→「家族が作った家計に参加する」にコードを入力
4. 子どもなどログインしない人は「設定 → メンバー」で追加できる(「精算に含める」をオフにすると割り勘の対象外)

スマホでは、ブラウザの共有メニューから「ホーム画面に追加」するとアプリのように使えます。

### 精算の考え方

- 支出は、そのままでは精算に入らない(自動では割り勘にしない)
- 割り勘にしたい支出だけ、入力画面の **「👥 メンバーで分割」** ボタンを押す。スワイプ入力のあとは、上に出る通知の「分割」を押す。あとからでも「履歴」で開いて切り替えられる
- 分割にした支出を、精算に含めるメンバーで均等に割り、払いすぎている人へ渡す金額を「精算」に表示
- 実際にお金を渡したら「渡したら記録」を押すと差し引かれる
- 「分割した支出を見る」で一覧を確認できる。「すべて解除して、精算をゼロに戻す」を押すと、分割の指定と精算の記録をまとめて消して最初からやり直せる(支出そのものは消えない)

## インターネットに公開する

HTML/CSS/JavaScript だけの静的サイトなので、GitHub Pages・Cloudflare Pages・Netlify など好きな場所にフォルダごと置けば動きます(ビルド作業は不要)。公開後、Supabase の **Authentication → URL Configuration → Site URL** に公開URLを設定してください。

## フォルダ構成

```
index.html              画面の土台
css/style.css           見た目
js/config.js            クラウド同期の設定(ここだけ編集する)
js/app.js               画面と操作
js/logic.js             計算(精算・固定費・集計)
js/backend-local.js     お試しモードの保存
js/backend-supabase.js  クラウドモードの保存
supabase/schema.sql     データベース定義(Supabase に貼り付ける)
sw.js, manifest.webmanifest, icons/   ホーム画面追加・オフライン用
tests/                  計算のテストと動作確認用ページ
```

計算のテスト: `node --test tests/logic.test.mjs`
